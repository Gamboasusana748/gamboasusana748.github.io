🎯 What is agent-monitor?

If you use AI coding assistants like Codex or Claude Code, you might wonder what exactly those background "subagents" are doing. agent-monitor pulls back the curtain, showing you everything in a clean, easy-to-understand dashboard so you can optimize your workflow and save money.

Think of it like a "flight recorder" for your AI helpers. You'll see every step they take, every token they use, and exactly how much it costs you.

✨ Key Features

🔄 Advanced Traces View

See each subagent's complete task list, decision points, and output generation in a tree-style trace. No more guessing what happened in the background.

📊 Token Breakdown

Understand exactly how many input versus output tokens each subagent consumed. Identify wasteful patterns and make your AI usage more efficient.

💰 Cost Usage Tracking

Get real-time cost estimates per session, per subagent, or per day. Avoid surprise bills and stay within your budget while using AI.

📈 Live Monitoring

Watch subagents work in real-time with a live dashboard. See new traces appear as your AI gets to work, and get instant updates on token usage.

🛠️ Troubleshooting & Help

I see "No Data Available"

This usually means you haven't started a session with Codex or Claude Code yet, or the app is waiting for new activity. Launch one of your AI tools, do a task for a minute or two, then check agent-monitor's dashboard again.

The download didn't work

Make sure your internet connection is stable and try using a different browser (like Chrome or Edge). If it still fails, try downloading the alternate .zip version instead of the .exe.

Windows SmartScreen warning

When launching for the first time, Windows might show a blue "Windows protected your PC" screen. If you trust the source, click "More info" then "Run anyway". This happens with new software from small developers.
